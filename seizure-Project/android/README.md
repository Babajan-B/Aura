# Aura Guard - Android

Multi-module skeleton for the **Aura Watch** seizure pre-ictal detection
project. The phone runs the RGF-Net TFLite model; the Wear OS watch app
captures sensors, ships them over the Wear Data Layer, and shows the
alert + 15s countdown.

## Modules

| Module    | Type            | Purpose                                                |
| --------- | --------------- | ------------------------------------------------------ |
| `:app`    | Phone app       | TFLite inference, dashboard UI, SOS dispatcher, log DB |
| `:wear`   | Wear OS app     | Sensor capture (accel @ 50Hz, HR @ 1Hz), alert UX      |
| `:shared` | Pure Kotlin lib | `SensorPacket` data model used on both sides           |

## Toolchain

- Android Gradle Plugin **8.5.2**
- Kotlin **2.0.20** (Compose Compiler plugin)
- Compose BOM **2024.10.00**
- Wear Compose **1.4.0**
- TensorFlow Lite **2.16.1**
- JDK **17**

## How to run (no CI required)

1. Open this folder in **Android Studio Hedgehog (2023.1.1)** or newer.
   Studio will offer to download Gradle 8.9 and regenerate the wrapper
   JAR — accept.
2. Place the trained model at:
   ```
   app/src/main/assets/rgf_net.tflite
   ```
   Until then, `InferenceEngine` falls back to a deterministic stub score
   so the dashboard still renders cleanly on a fresh emulator.
3. Run **`:app`** on a phone emulator
   - Recommended: **Pixel 7, API 34** (Android 14)
   - Grant `BODY_SENSORS`, `SEND_SMS`, `CALL_PHONE`, `ACCESS_FINE_LOCATION`,
     `POST_NOTIFICATIONS` when prompted.
4. Run **`:wear`** on a Wear OS emulator
   - Recommended: **Wear OS 4, API 33** (e.g. *Wear OS Small Round*).
   - Pair the Wear emulator to the phone via the Companion app, or use
     Studio's `Device Manager → Pair` flow.

## Layout

```
android/
  settings.gradle.kts
  build.gradle.kts
  gradle.properties
  gradle/wrapper/gradle-wrapper.properties   # jar regenerated by Studio
  app/
    build.gradle.kts
    src/main/
      AndroidManifest.xml
      assets/PLACE_TFLITE_HERE.txt           # drop rgf_net.tflite here
      kotlin/com/auraguard/phone/
        MainActivity.kt
        ui/{DashboardScreen,EventLogScreen}.kt
        ml/{InferenceEngine,RingBuffer}.kt
        wear/WearDataListenerService.kt
        sos/EmergencyDispatcher.kt
        data/EventLogDao.kt
  wear/
    build.gradle.kts
    src/main/
      AndroidManifest.xml
      kotlin/com/auraguard/wear/
        MainActivity.kt
        ui/{MonitoringScreen,AlertCountdownScreen}.kt
        sensors/SensorService.kt
        comms/PhoneBridge.kt
  shared/
    build.gradle.kts
    src/main/kotlin/com/auraguard/shared/SensorPacket.kt
```
